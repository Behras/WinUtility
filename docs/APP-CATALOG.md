# Bundled app catalog

Checked on **2026-09-15** against package directories in Microsoft's WinGet
manifest repository. The 48 entries below are choices for laptop setup, with
short descriptions written for this project. No installers were downloaded or
executed during this catalog check. Availability and installer behavior still
depend on WinGet, Windows architecture, machine policy and the publisher.

Use **App installs** to browse these categories. `S` searches names, descriptions,
categories and IDs; `B` shows the full local list. Enter `1,3,5-7` to toggle
several visible apps, or `A` / `C` to select / clear that page. Selections carry
across pages, categories and searches. `R` opens the installation review.
Arrow keys move the highlight; **Space** or **Enter** toggles an app. **Esc** goes
back, and **Left/Right** changes pages when no shortcut is being typed.

On Windows, `W` searches the live `winget` source beyond this list. Paste one or
more complete, exact IDs; WinUtility verifies each with `winget show`, displays
the details and asks before queueing the batch. Additional packages are labeled
by their ID under **From WinGet** and are included in exported setups.
